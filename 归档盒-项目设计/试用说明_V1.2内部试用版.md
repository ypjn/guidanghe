# 归档盒 V1.2 内部试用版 · 试用说明

> **开始前请先读这两句**：
> 1. 整理是**移动文件，不是备份**——操作不可用"还原系统"找回，请
>    首次试用先用一份**独立副本**（比如把某个课程文件夹复制到桌面
>    的"试用副本"目录），确认行为符合预期后再整理真实资料。
> 2. 真实 NEU 资料目录在试用期间保持**只读**，不要直接对它执行整理。

## 一、启动

- 双击项目文件夹里的 **`启动归档盒.command`**（Finder 中双击，或右键→打开）。
- 会打开一个终端窗口和归档盒主窗口；关闭归档盒窗口后终端提示退出。
- 启动失败时终端会给出原因（缺虚拟环境/缺源码），按提示操作即可，
  脚本不会自动安装或升级任何东西。

## 二、一次完整的整理流程

1. **选目录**：点「浏览…」选择要整理的课程文件夹（根目录），点「扫描」。
2. **看预览**：扫描后点「重新预览」生成计划。表格列出每个文件的
   原位置 → 目标位置、分类依据和大小；底部状态栏显示总件数与
   受保护目录数量。**此时文件还没被移动**。
3. **确认整理**：核对无误后点「开始整理」，确认对话框里再点一次确认。
   整理进度在底部进度条与状态栏显示。
4. **完成后**：主窗口提示结果（成功/跳过/失败数量），可点「操作历史」查看。

## 三、设置保护目录

- 点「保护目录…」可手动添加**不想被整理**的目录（如"个人文件"）。
- 程序也会**自动识别项目目录**（含 `.git` 等标记的课程项目）并整体保护，
  预览底部状态栏会显示"受保护目录 N 个，跳过 M 个文件"。

## 四、查看历史 / 撤销 / 核对恢复

- **操作历史**：每个批次一行（时间、状态、移动/跳过/失败/取消/撤销
  计数）；点批次看逐项明细，支持搜索、状态筛选、分页、
  「在文件管理器中显示」定位、导出 CSV/JSON。
- **撤销**：只能撤销**最近一个尚未完全撤销的批次**（选中旧批次时
  按钮会禁用并说明原因）。撤销把已移动的文件放回原位置。
- **核对恢复**：只用于**中断批次**（程序意外退出等）。它只核对磁盘
  实际情况并补记状态——已移动但没记录的补记为"已移动"，没动的
  保持"未执行"，说不清的标"暂停"。**它不会移动任何文件**；
  要把文件放回去，核对后再用「撤销」。

## 五、各种状态是什么意思

| 状态 | 含义 | 你要做什么 |
|---|---|---|
| 取消 | 你点了取消；已完成项保留，剩余项记为取消 | 无需处理，可正常撤销 |
| 关闭等待 | 有任务在后台运行时你关了窗口 | 等它自动结束，窗口会自己关闭 |
| 冲突 | 撤销时原位置已有新文件/目标被修改 | 程序**保留现状不动**，明细里有原因，需人工核对 |
| 暂停 | 中断恢复时磁盘状态不明确 | 人工确认文件在哪，再决定撤销或手动处理 |

## 六、保存截图 / 导出历史 / 反馈问题

- **截图**：macOS 用 `Cmd+Shift+4` 框选窗口；保存到
  `归档盒-项目设计/验收截图_...` 目录或任意位置。
- **导出历史**：历史窗口选中批次 →「导出…」→ 选 CSV 或 JSON。
- **反馈问题**：把①截图、②做了什么操作、③历史窗口里对应批次的
  明细（或导出的 CSV）记下来，追加到《归档盒-过程记录.md》或直接
  反馈给开发轮次。

## 七、每次试用后记什么（日常试用模板）

项目里已提供空白的 **《归档盒-日常试用记录.md》**。每次整理完，在
对应周期表里填一行即可：

1. **日期 / 整理目录 / 文件数 / 耗时**（历史窗口批次行有数量）；
2. **分类修正**：哪些文件被分错了，正确应该去哪（这是下一轮
   规则通用化最重要的输入）；
3. **遇到的问题**：冲突、暂停、异常退出等，附截图或导出文件；
4. **撤销/恢复情况**：是否用过、结果是否符合预期。

## 八、支持范围与已知限制

- 支持：单根目录内的课程资料整理（按学期/课程/类型）、固定计划
  预览、保护目录、撤销最近批次、中断批次核对恢复、完整历史。
- 不支持（后续版本）：跨磁盘移动、AI 自动分类、目录监测、
  Windows、通用规则引擎；恢复核对阶段不可取消（有进度显示）。
