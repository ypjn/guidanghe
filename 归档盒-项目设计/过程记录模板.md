# 归档盒：过程记录模板

本文件是空白模板，不是实验结果。每一次发送消息均单独编号；一个版本可以对应多次交互。

## 建议提交目录

```text
归档盒课程作业/
  程序代码/                 # TRAE 实际生成、修改的源码和运行说明
  过程证据/
    000-任务与预设标准/
    001-环境与只读初版/
      提示词原文.txt
      TRAE反馈原文.txt
      截图/
      运行记录.txt
      人工观察.md
      版本标识.txt
    002-实际交互主题/
    ...
  验收资料/
    测试数据说明.md
    各版本输入与前后清单/
    原始测试输出/
  报告.docx
```

证据和快照放在被整理目录之外。截图按顺序编号，不覆盖原图；保留所有追加、修订和纠错消息。没有确认聊天导出功能时，以即时保存原文和连续截图作为基础，不等项目结束后补记。
