# 归档盒 V1.3 规则配置版 · 试用说明

> **先读这两句**：
> 1. 整理是**移动文件，不是备份**。首次试用请使用**独立副本**，
>    确认行为符合预期后再整理真实资料。
> 2. 真实 NEU 资料目录在试用期间保持**只读**，不要直接对它执行整理。

## 一、本版新增：不用改源码就能调整推荐模式

推荐模式（「按方向/学期/类别」）的方向、学期、课程目录与关键词兜底，
现在可以在界面里编辑，并**按根目录保存**、重启后恢复。

配置文件位置：`{你选择的根目录}/.organizer/classification_config.json`
（只有你点击「保存并应用」才会创建；只查看/试运行不会写文件。）

## 二、启动

- 双击项目根目录的 **`启动归档盒.command`**（Finder 双击或右键→打开）。
- 复用 `归档盒源码/.venv`；脚本不会自动升级依赖或更换系统 Python。
- 启动失败时终端会给出原因（缺虚拟环境/缺源码），按提示处理即可。

## 三、推荐模式的规则编辑流程

1. 选择目录 →「扫描」→ 确认当前「分类模式」为
   **按方向/学期/类别（推荐）**。
2. 点 **「推荐模式配置…」** 打开编辑器。五张表分别对应：
   - 学期映射：来源目录名 → 学期标签；
   - 顶层方向：顶层目录 → 课程/竞赛/项目/校园事务；
   - 学期内目录：某学期下的一级目录 → 方向 + 类别（类别留空=用关键词细分）；
   - 通用目录前缀：未登记目录按前缀归类（如「附件-」）；
   - 关键词兜底：关键词 → 目标类别，可选匹配范围与触发场景。
3. 每张表里：勾选=启用；行从上到下就是匹配优先级；用「上移/下移」调整；
   「添加一行 / 删除选中」维护规则。
4. 点 **「试运行／查看影响…」**：用当前草稿与已生效配置对比，显示
   - 样本数量、各规则命中数量、未匹配（待定）数量；
   - 哪些文件的原目标/新目标发生变化；
   - 代表性文件的分类依据与预计目标。
   试运行**不移动文件、不创建分类目录、不写历史**，也不计算 SHA-256
   （因此“内容重复”一栏会明确标注未核验）。
5. 满意后点 **「保存并应用」**。保存成功后：
   - 旧预览立即失效，「开始整理」被禁用；
   - 必须点 **「重新预览」** 按新规则生成计划，再确认整理。
6. 点「取消」不会改变已生效规则和配置文件；「恢复默认」会把编辑框
   恢复为内置默认，保存后才真正删除该目录的自定义配置。

## 四、各模式实际使用哪些配置

| 模式 | 使用的规则 |
|---|---|
| 按类型 | 不使用本配置；按扩展名类型分目录 |
| 按课程再按类型 | 使用主窗口「编辑课程规则…」里的课程关键词（只影响该模式） |
| 按方向/学期/类别（推荐） | 使用「推荐模式配置…」中的五类映射与关键词兜底 |

因此，两个配置按钮只在各自生效的模式下可点击，避免“能编辑但当前模式
根本不使用”。

推荐模式的固定匹配顺序：
**学期映射 → 顶层方向 → 学期内目录（类别留空时用关键词）→ 通用目录前缀
→ 未登记目录按目录名锚定 → 待定**。
未匹配的内容进入 `_已整理/待定/…`，不会强行猜测。

## 五、配置损坏或不可用时

- 如果配置文件损坏、版本不兼容、字段非法或不属于当前目录，软件会：
  - 明确提示原因，**保留原文件**；
  - **不允许**推荐模式生成计划（不会静默回退默认规则后继续执行）。
- 处理方式：打开「推荐模式配置…」，用默认规则作草稿修复；
  只有点击「保存并应用」才会覆盖原文件；取消则原文件保持不变。
- 保存失败（如磁盘不可写）时，旧配置与已生效规则保持原样，
  界面不会显示虚假的“已保存”。

## 六、历史中的配置快照

每个批次会保存**当时实际使用的分类配置快照**。历史窗口选中批次后，
下方会显示该批次的配置摘要；以后修改规则不会改变旧批次的记录，
便于解释“当时为什么分到这里”。

## 七、其他日常操作

- **保护目录**：「保护目录…」添加不想被整理的目录；自动识别的项目根
  与程序自身源码默认保护。分类配置**不能**解除这些保护。
- **撤销**：只能撤销最近一个尚未完全撤销的批次；冲突时保留现状并写明原因。
- **核对恢复**：只核对中断批次的磁盘实际状态并补记，不移动文件。
- 取消、关闭等待、冲突、暂停的含义与 V1.2 试用说明一致。

## 八、保存截图 / 导出历史 / 反馈问题

- 截图：`Cmd+Shift+4` 框选窗口；
- 导出：历史窗口选中批次 →「导出…」→ CSV/JSON；
- 反馈：截图 + 做了什么操作 + 对应批次明细/导出文件，追加到
  《归档盒-过程记录.md》或直接反馈给开发轮次。
- 每次试用后按《归档盒-日常试用记录.md》填：日期/目录/文件数、
  分类修正、遇到的问题、撤销/恢复情况。**分类错例请尽量保留**，
  它是下一轮规则改进的输入。

## 九、支持范围与已知限制

- 支持：单根目录课程资料整理、推荐模式规则配置、按根保存/重启恢复、
  规则影响试运行、保护目录、撤销最近批次、中断核对恢复、完整历史。
- 不支持（后续版本）：跨磁盘移动、AI/OCR 分类、目录监测、Windows、
  任意方向与目标路径模板、任意脚本规则。
- 试运行不计算 SHA-256，重复信息需在正式预览/计划中核验。
- 恢复核对阶段不可取消（有进度显示，符合设计）。
- 整理记录不等于备份；重要资料请先做独立备份。
