# 归档盒 V1.7 重复核对与日常入口版 · 试用说明（基于 V1.3 规则配置 / V1.4 单文件修正 / V1.5 长期规则 / V1.6 方案与预览）

> **先读这两句**：
> 1. 整理是**移动文件，不是备份**。首次试用请使用**独立副本**，
>    确认行为符合预期后再整理真实资料。
> 2. 真实 NEU 资料目录在试用期间保持**只读**，不要直接对它执行整理。

## 一、本版新增：不用改源码就能调整推荐模式

推荐模式（「按方向/学期/类别」）的方向、学期、课程目录与关键词兜底，
现在可以在界面里编辑，并**按根目录保存**、重启后恢复。

配置文件位置：`{你选择的根目录}/.organizer/classification_config.json`
（只有你点击「保存并应用」才会创建；只查看/试运行不会写文件。）

## 二、启动

- 双击项目根目录的 **`启动归档盒.command`**（Finder 双击或右键→打开）。
- 复用 `归档盒源码/.venv`；脚本不会自动升级依赖或更换系统 Python。
- 启动失败时终端会给出原因（缺虚拟环境/缺源码），按提示处理即可。

## 三、推荐模式的规则编辑流程

1. 选择目录 →「扫描」→ 确认当前「分类模式」为
   **按方向/学期/类别（推荐）**。
2. 点 **「推荐模式配置…」** 打开编辑器。五张表分别对应：
   - 学期映射：来源目录名 → 学期标签；
   - 顶层方向：顶层目录 → 课程/竞赛/项目/校园事务；
   - 学期内目录：某学期下的一级目录 → 方向 + 类别（类别留空=用关键词细分）；
   - 通用目录前缀：未登记目录按前缀归类（如「附件-」）；
   - 关键词兜底：关键词 → 目标类别，可选匹配范围与触发场景。
3. 每张表里：勾选=启用；行从上到下就是匹配优先级；用「上移/下移」调整；
   「添加一行 / 删除选中」维护规则。
4. 点 **「试运行／查看影响…」**：用当前草稿与已生效配置对比，显示
   - 样本数量、各规则命中数量、未匹配（待定）数量；
   - 哪些文件的原目标/新目标发生变化；
   - 代表性文件的分类依据与预计目标。
   试运行**不移动文件、不创建分类目录、不写历史**，也不计算 SHA-256
   （因此“内容重复”一栏会明确标注未核验）。
5. 满意后点 **「保存并应用」**。保存成功后：
   - 旧预览立即失效，「开始整理」被禁用；
   - 必须点 **「重新预览」** 按新规则生成计划，再确认整理。
6. 点「取消」不会改变已生效规则和配置文件；「恢复默认」会把编辑框
   恢复为内置默认，保存后才真正删除该目录的自定义配置。

## 四、各模式实际使用哪些配置

| 模式 | 使用的规则 |
|---|---|
| 按类型 | 不使用本配置；按扩展名类型分目录 |
| 按课程再按类型 | 使用主窗口「编辑课程规则…」里的课程关键词（只影响该模式） |
| 按方向/学期/类别（推荐） | 使用「推荐模式配置…」中的五类映射与关键词兜底 |

因此，两个配置按钮只在各自生效的模式下可点击，避免“能编辑但当前模式
根本不使用”。

推荐模式的固定匹配顺序：
**学期映射 → 顶层方向 → 学期内目录（类别留空时用关键词）→ 通用目录前缀
→ 未登记目录按目录名锚定 → 待定**。
未匹配的内容进入 `_已整理/待定/…`，不会强行猜测。

## 五、配置损坏或不可用时

- 如果配置文件损坏、版本不兼容、字段非法或不属于当前目录，软件会：
  - 明确提示原因，**保留原文件**；
  - **不允许**推荐模式生成计划（不会静默回退默认规则后继续执行）。
- 处理方式：打开「推荐模式配置…」，用默认规则作草稿修复；
  只有点击「保存并应用」才会覆盖原文件；取消则原文件保持不变。
- 保存失败（如磁盘不可写）时，旧配置与已生效规则保持原样，
  界面不会显示虚假的“已保存”。

## 六、历史中的配置快照

每个批次会保存**当时实际使用的分类配置快照**。历史窗口选中批次后，
下方会显示该批次的配置摘要；以后修改规则不会改变旧批次的记录，
便于解释“当时为什么分到这里”。

## 七、其他日常操作

- **保护目录**：「保护目录…」添加不想被整理的目录；自动识别的项目根
  与程序自身源码默认保护。分类配置**不能**解除这些保护。
- **撤销**：只能撤销最近一个尚未完全撤销的批次；冲突时保留现状并写明原因。
- **核对恢复**：只核对中断批次的磁盘实际状态并补记，不移动文件。
- 取消、关闭等待、冲突、暂停的含义与 V1.2 试用说明一致。

## 八、保存截图 / 导出历史 / 反馈问题

- 截图：`Cmd+Shift+4` 框选窗口；
- 导出：历史窗口选中批次 →「导出…」→ CSV/JSON；
- 反馈：截图 + 做了什么操作 + 对应批次明细/导出文件，追加到
  《归档盒-过程记录.md》或直接反馈给开发轮次。
- 每次试用后按《归档盒-日常试用记录.md》填：日期/目录/文件数、
  分类修正、遇到的问题、撤销/恢复情况。**分类错例请尽量保留**，
  它是下一轮规则改进的输入。

## 九、单文件分类修正（V1.4 新增）

当自动分类对某个文件不合适时，不必改规则重跑。在预览表格里：

> **适用范围**：本功能**只在「按方向/学期/类别（推荐）」模式**下可用。
> 「按类型」「按课程再按类型」模式下按钮为灰色；直接调用也会被拒绝，
> 因为这两种模式不记录方向/学期/类别，无法"恢复自动分类"。
> 需要修正它们时，请用对应的规则配置入口。

1. 选中一行（只支持单行）。
2. 点 **「修正所选文件分类…」** 按钮。弹出对话框，左侧显示当前文件的
   自动分类依据（方向 / 学期 / 类别 / 自动规则 / 自动目标路径），
   右侧是可编辑字段：
   - **方向**：课程 / 竞赛 / 项目 / 校园事务 / 待定（下拉选择）
   - **学期**：课程方向必填；其他方向留空
   - **类别**：分类到该方向下的子目录名（留空则用自动分类的类别）
   - **内部路径**：留空则保持自动分类的内部层级。可以填一层（`实验一`），
     也可以填多层（`实验一/分组报告`），程序会逐段校验后用 `/` 还原成子目录。
     开头、连续或结尾出现 `/` 会被拒绝。
   - **说明**：可选文字，写入历史记录，便于日后追溯
3. **字段实时预览目标路径**——每改一个字段，下方立即更新预计目标。
   路径非法（如包含 `..`、以 `/` 开头、出现空目录段）时字段显示红色，
   且「确定」按钮禁用。
4. 改好了点「确定」。应用后：
   - 当前表格中该文件所在行**整行变黄**，源路径列前加 `✎` 标记，
     tooltip 显示"自动 → 手动"对比；
   - 状态栏提示"已手动修正 N 个文件"；
   - 冲突重新计算（如果两个文件修正后目标重名，程序自动加 `(1)` / `(2)` 后缀）。
5. 要**恢复自动分类**有三种方式：
   - 对话框里点「恢复自动分类」按钮（会连原有「作业」「实验」这类内部目录
     一起还原，不会丢层）；
   - 主窗口选中已修正行，再次点「修正所选文件分类…」→ 改回原始值；
   - **重新扫描 / 重新预览 / 切换根目录**都会丢弃当前计划，自动生效。

### ⚠ 重要：修正只在"本次计划"生效

- 修正**不写回分类配置**，也不影响其他根目录的默认分类。
- 重新扫描 / 重新预览 / 切换根目录 → 当前计划丢弃，手动修正消失。
- 保存配置 → 旧计划同样会立即失效（这是 V1.3 已有的门控，本轮不变）。
- 整理执行后，历史批次里每条记录会标注"分类来源=手动/长期规则/自动"，
  手动修正的行 tooltip 显示"自动目标 → 手动目标 → 修正说明"，
  长期规则的行 tooltip 显示规则标识与命中依据（见 10.4）。

### 与其他功能的互斥关系

| 操作 | 对手动修正的影响 |
|---|---|
| 重新扫描 | 丢弃当前计划，修正消失 |
| 重新预览 | 丢弃当前计划，修正消失 |
| 切换根目录 | 丢弃当前计划，修正消失 |
| 保存分类配置 | 旧计划失效，重新生成后修正消失 |
| 执行整理 | 修正随批次一起入库，历史可追溯 |
| 撤销 | 不关心当初是自动还是手动，只按 SHA 恢复 |

### 取消 = 不改计划

对话框点「取消」或关闭窗口 → 计划不变，什么都不做。
只有点「确定」才应用到当前计划。

## 十、保存为长期规则（V1.5 新增）

如果这次修正以后还会反复遇到，可以在同一个修正对话框里点
**「保存为长期规则…」**，把这次判断固化成规则。

### 10.1 操作流程

1. 在预览中修正一个文件，字段改好后，点「保存为长期规则…」。
2. 弹出规则草稿窗口，自动带入这次的目标分类，你只需要确认/修改匹配条件：
   - **匹配方式**（三选一，没有正则、没有脚本）：
     - **精确路径**（默认）：只匹配这一个文件
     - **目录范围**：整个来源目录；可勾选「包含子目录」
     - **文件名关键词**：文件名含任一关键词；可限定来源目录
   - **来源路径/目录**：按匹配方式填写，目录匹配一律按路径边界判断，
     「课程A」不会误匹配「课程AB」
   - **目标方向 / 学期 / 类别**：沿用现有方向与路径模板
   - **内部路径**：保留自动结果 / 清空 / 替换为指定路径
3. 点 **「试运行」**，下方展示：
   - 命中文件数、目标位置变化数、目标冲突数
   - 代表样本的原位置、旧目标、新目标与命中依据
   - 试运行在**后台线程**执行，计算期间窗口仍可拖动、可关闭，
     按钮与输入框暂时锁定并提示「试运行中……」；关掉窗口会安全取消，
     迟到结果不会再回填。
4. 点 **「保存为长期规则」**，确认框会再次说明影响；确认后写入该根目录配置。
   - 保存只使用**上次试运行的结果**，不会在保存时再同步算一遍；
   - 若修改了匹配条件或目标字段（**包括内部路径的方式与取值**），
     需要**重新试运行**才能保存（下方会提示「匹配条件或目标已修改，请重新试运行」）。

### 10.2 优先级（重要）

```
当前计划的临时手动修正   ← 最高
        ↓
已启用的长期修正规则（从上到下取第一条命中）
        ↓
原有推荐模式映射（学期 / 顶层方向 / 学期内目录 / 通用前缀 / 关键词）
```

因此长期规则**能覆盖**已经命中原有学期/课程映射的文件，
但仍不会改写保护目录的判断——保护目录始终由保护机制控制。

### 10.3 保存后会发生什么

- 规则写入 `{根目录}/.organizer/classification_config.json`，重启后继续生效；
- **当前计划的临时手动修正会一起失效**（保存前会明确提示）；
- 旧预览失效，需要点「重新预览」按新规则生成计划后才能执行；
- 之后可在「推荐模式配置 → 长期修正规则」页查看、编辑、启用/禁用、删除、上移/下移。

历史记录里每个文件都会保留**当时实际命中的规则标识与依据**，
即使后来规则被改、被禁用或被删除，旧批次记录也不会变。

### 10.4 在哪里查看长期规则结果

- **历史窗口 → 选中批次 → 逐项明细**：
  - 「分类来源」列现在有三种取值：**手动**、**长期规则**、**自动**；
    长期规则行以蓝色显示，自动行保持灰色；
  - 把鼠标停在「分类来源」上，可看到**规则标识**（如 `long_term:lt-…`）
    与**命中依据**（例如「长期规则「作业 修正规则」：来源目录
    「大二上/数据结构」（含子目录） → 项目/数据大创」）；
  - 批次列表的「注意」列会显示「⚑ 长期规则×N」，一眼看出该批次
    有多少条是靠长期规则分类的。
- **导出**：
  - JSON 每条动作新增 `rule_key`（如 `long_term:lt-…`）与
    `rule_applied`（命中依据文本）；
  - CSV 新增「规则标识」「命中依据」两列。
  - 旧批次（V1.5 之前）这两项为空，导出时同样保留空值，不做推断。

### 10.5 配置版本兼容

配置格式升到 `version=2`。读取端同时接受 1 和 2：
- 旧配置（version 1，没有长期规则）**可正常读取**，保存时自动升级为 2；
- 新配置（version 2）用旧程序打开会因版本不兼容被拒绝，并保留原文件——
  避免旧程序静默忽略长期规则后继续整理。

### 10.6 取消 / 失败时的状态

- 草稿窗口点「取消」：不写配置，草稿丢弃；
- 规则校验不通过（空名称、路径逃逸、学期与方向不匹配等）：拒绝保存并指出原因；
- 保存失败：原配置文件保持字节不变，已生效规则不改变。

## 十一、整理方案：导入、导出与方案库（V1.6 新增）

入口：主窗口第二行 **「整理方案…」**。所有方案只包含
**推荐模式配置 + 长期修正规则**，不包含「按类型」「按课程再按类型」的
独立规则，也不包含保护目录、历史数据库、文件清单、文件指纹、
临时手动修正或本机环境路径。

### 11.1 导出当前配置

- 在方案库窗口点 **「导出当前配置…」**，填写方案名称并选择保存位置；
- 方案文件是 UTF-8 JSON，带 `format=archive-box-scheme` 与
  `format_version`，含方案名、说明、导出时间、配置版本、各类规则数量；
- 长期规则的来源/内部路径统一使用 `/` 分隔，跨平台可迁移；
- 导出文件**不携带**当前根目录绑定，可在另一个整理目录导入。

### 11.2 导入先形成草稿

- 点 **「导入方案文件…」**：先读取并校验，**不会立即覆盖**当前配置；
- 窗口中显示来源名称/说明、格式与配置版本、各类规则数量、
  长期规则启用数量与兼容性提示；
- 以下情况会明确报错并保留原文件与当前状态：损坏 JSON、未知格式、
  不支持格式/配置版本、字段类型错误、非法或逃逸路径、规则校验失败；
- 旧版本配置（v1，无长期规则）可读入并升级为 v2，窗口会提示已升级。

### 11.3 替换与合并

导入方案后选择应用方式：

- **替换**：用方案完整替换当前目录的推荐模式配置；
- **合并**（现有优先）：
  - 现有规则保留，导入的新规则加入；
  - 相同标识且内容一致的长期规则直接跳过；
  - 相同标识但内容不同 → 列为冲突，逐条选择「保留现有 / 采用导入」；
  - 长期规则同名但标识不同 → 列为冲突，默认保留现有；
  - 学期/方向/前缀/关键词等映射冲突 → 保留现有并明确列出；
  - 学期内目录引用了合并后不存在的学期 → 该条跳过并提示，
    **不会猜测学期关联**；
  - 合并结果必须再次通过配置校验，否则拒绝应用；
- 稳定标识在替换/合并中保留；只有用户显式选择「采用导入」时，
  才用导入规则的标识与内容替换现有同名/同标识规则。

### 11.4 差异与影响预览

确认应用前会显示：

- 新增 / 修改 / 删除 / 跳过 / 冲突条数；
- 长期规则顺序（前 → 后）；
- 若当前目录已有扫描结果：后台线程计算命中数、目标变化数与代表样本
  （不移动文件、不计算 SHA-256、不写执行历史）；
- 若尚未扫描：明确提示「暂不能计算文件影响」，仍可查看配置差异；
- 计算期间窗口保持响应，可取消；计算完成前不能点「确认应用」。

### 11.5 应用与回退

- 应用时**重新绑定当前根目录**；该目录的保护设置、历史记录和
  实际文件保持不变；
- 保存成功后旧预览立即失效，必须点「重新预览」才能执行；
- 保存失败时原配置与当前状态保持不变；
- 每次确认应用前会把当时的配置备份到
  `{根目录}/.organizer/config_backups/`（最多保留 5 份）；
- **备份失败会停止应用**：不会出现“配置已改变但无法恢复”的情况，
  原配置与当前计划状态保持不变；
- 方案库窗口的 **「恢复上一次配置」** 会恢复最近一次应用前的配置：
  - 只改变分类配置，不移动或撤销任何文件；
  - 恢复后旧预览同样失效；
  - 原来使用内置默认时，可恢复为默认状态（删除自定义配置文件）；
  - 损坏的配置备份会保留但不能被启用；
  - 备份按根目录隔离。

### 11.6 本地方案库

- 方案库位于系统用户配置目录，不在源码目录或扫描根目录：
  - macOS：`~/Library/Application Support/归档盒/schemes`
  - Windows：`%APPDATA%\归档盒\schemes`
  - Linux：`$XDG_CONFIG_HOME/归档盒/schemes`（或 `~/.config/归档盒/schemes`）
- 至少包含两个只读内置方案：**内置默认方案**、**空白方案**；
- 支持：从当前配置保存为方案、复制、修改名称/说明、删除自定义方案、
  导入方案文件到方案库、导出所选方案；
- 内置方案只读，可复制后编辑；
- 应用方案时总是把内容**复制**到当前目录配置，目录之间不共享可变对象；
  之后修改或删除方案库模板，不会改变已应用目录的配置；
- 方案标识只允许字母、数字、下划线和连字符；导入文件里的非法标识
  会被替换为新的安全标识，**不会写出方案库目录之外**；
- 方案编辑沿用现有「推荐模式配置…」编辑器与校验机制。

## 十二、预览搜索、筛选、批量勾选与目标树（V1.6 新增）

### 12.1 搜索与筛选

预览表格上方新增筛选条：

- 搜索：同时匹配**源相对路径、目标相对路径、分类依据**；
- 文件类型、目标方向；
- 分类来源：自动 / 长期规则 / 本次手动修正；
- 仅待定、仅重名或经过冲突改名的条目；
- 默认展示全部；「清空筛选」恢复全部可见。

筛选**只改变视图**，不改变计划内容、分类结果或规则；
切换根目录、计划失效或重新生成计划时，旧筛选状态会自动清空。
手动修正改变某个文件的方向或类型后，筛选项会自动刷新；
仍然有效的当前筛选条件会保留，不存在的选项回落到「全部」。

### 12.2 批量勾选与执行确认

- **勾选可见 / 取消勾选可见 / 反选可见** 只作用于当前可见行；
- 筛选变化不会改变隐藏行的勾选状态；
- 计数栏显示：计划总数、可见数、已勾选数、隐藏但仍勾选数；
- 「开始整理」按**全部勾选项**执行；确认窗口会提示隐藏但仍勾选的
  文件数量，避免误以为只处理当前可见行；
- 单文件修正仍按「当前计划 + 根目录 + 源相对路径」定位文件，
  筛选、排序或同名文件都不会改错对象；
- 忙碌与关闭等待期间，筛选、批量勾选和目标树入口一并禁用。

### 12.3 目标目录结构

- 点 **「查看目标目录结构…」** 打开树形视图；
- 只展示计划准备生成的目录层级、文件与数量，**不会创建真实目录**；
- 可查看完整目标路径（悬浮提示）；
- 可在「整份计划」与「当前筛选范围」之间切换；
- 筛选变化时由主窗口节流后刷新，不在每次输入字符时重建整棵树。

## 十三、重复文件查看（V1.7 新增）

入口：主窗口 **「重复文件…」**。只读核对，不删除、不合并、不移动，
也不改变计划勾选。

### 13.1 范围与分组

- 范围：**当前整理空间、当前扫描纳入的文件**；
  不宣称已核对整块硬盘，也不包含被保护/排除的区域；
- **内容重复**：SHA-256 已核对且一致，组内至少 2 份；
- **同名不同内容**：名称相同、全部成员已核对且存在不同指纹；
- **同名（待核对）**：同名组中有成员未完成核对；
- **待核对 / 核对失败**：缺失指纹、读取失败、文件消失等，
  不能作为内容相同或不同的证据；
- 统计分别显示“组数”和“组内文件份数”；大小仅为文件大小，
  不代表可回收磁盘空间。

### 13.2 指纹复用与失效

- 优先复用有效计划中已计算的内容指纹；
- 文件大小或修改时间与扫描记录不一致时，旧指纹作废并重新核对；
- **关闭窗口后重新打开时**会先按文件大小/修改时间校验缓存：
  未变化项直接复用指纹，变化或缺失项才在后台重新核对；
  不会因“上次结论仍在”而继续展示过期分组；
- 未计算指纹（试运行/未算重复）时才在后台读取内容；
- 整理、撤销、重新扫描、切换根目录后旧结果失效，窗口关闭；
- 重复核对在后台线程执行，显示进度与当前文件，可取消；
  关闭窗口只请求取消，不阻塞界面；关闭程序会等待线程结束。

### 13.3 展示与操作

- 重复组可展开：文件名、源相对路径、完整路径、大小、
  核对状态、指纹、当前计划目标位置、组内份数；
- 支持搜索文件名/路径、按结果类型筛选；
- 支持打开所选文件、在系统文件管理器中定位、复制完整路径；
- 打开/定位前检查文件仍存在，文件消失时明确提示；
- 支持导出当前核对结果为 CSV/JSON，携带范围、核对时间、
  状态与指纹；未核对项不会写成“已确认重复”。

## 十四、日常整理入口（V1.7 新增）

### 14.1 最近整理空间

- 主窗口 **「最近空间…」**：显示目录名称、完整路径、最近打开时间、
  是否固定、是否可用；
- 支持打开、固定/取消固定、从记录中移除；
- 记录保存在系统用户配置目录（与方案库同一应用标识），
  属于本机使用状态，**不进入方案文件或 Windows 交接包**；
- 移除记录不会删除真实目录、配置、历史或文件；
- 目录不存在只标记“不存在或设备尚未挂载”，点击不会自动创建目录。

### 14.2 待整理清单

- 主窗口 **「待整理清单…」**，或直接把文件/文件夹拖到主窗口；
- 每项显示完整路径与类型；支持添加、移除、清空；
- 同一来源只登记一次；子项已被目录覆盖时不重复加入；
  后加入父目录时合并其下已有子项；
- 尚未选择空间时：
  - 单个目录可作为候选整理空间，由用户明确确认；
  - 文件或无法归属的来源会被拒绝；
- 当前空间之外的来源明确拒绝，**不会静默把共同父目录设为新根**，
  也不会生成混合根目录批次；
- 只登记范围，不移动文件、不写执行历史。

### 14.3 范围扫描与计划

- 「扫描」= 扫描当前整个整理空间；
  「扫描清单范围」= 只扫描清单指定的文件/目录；
- 清单扫描仍经过既有保护、项目识别和排除机制；
  不能绕过保护直接把路径交给计划器；
- 计划只包含清单范围，范围外文件保持原位；
- 界面分别说明纳入、受保护/被排除、未进入扫描、无效来源；
- 待整理范围变化时旧计划立即失效，必须重新预览；
- 忙碌或关闭等待期间，最近空间、待整理清单、
  扫描清单范围、重复文件入口一并禁用；
- 进入空间后可随时打开「整理方案…」，复用差异预览、确认、
  备份与应用流程。

## 十五、支持范围与已知限制

- 支持：单根目录课程资料整理、推荐模式规则配置、按根保存/重启恢复、
  规则影响试运行、**单文件手动分类修正**、**保存为长期修正规则**、
  **整理方案导入/导出/方案库/配置备份与回退**、
  **预览搜索筛选、可见批量勾选、目标目录结构树**、
  **重复文件核对（内容重复/同名不同内容/待核对）**、
  **最近整理空间、待整理清单与范围扫描**、
  保护目录、撤销最近批次、中断核对恢复、完整历史（含分类来源与规则标识）。
- 不支持（后续版本）：跨磁盘移动、AI/OCR 分类、目录监测、
  任意方向与目标路径模板、任意脚本规则、正则规则、多文件批量修正；
  Windows/Linux 仅保留兼容设计，尚未在原生平台验证。
- 试运行不计算 SHA-256，重复信息需在正式预览/计划中核验。
- 恢复核对阶段不可取消（有进度显示，符合设计）。
- 整理记录不等于备份；重要资料请先做独立备份。
- 手动修正只支持当前选中的**单行**；多行选中时对话框拒绝打开。
- 手动修正只在**推荐模式**下开放；其他模式请用对应规则配置入口。
- 长期规则同样只在**推荐模式**下生效；不改变「按类型」「按课程再按类型」。
- 内部路径的每一段仍会做非法字符替换，空段（`//`、首尾 `/`）直接拒绝。
- 「恢复自动分类」还原首次自动生成的快照（其中可能已包含长期规则的判断），
  不按当前配置重跑。
- 长期规则名称在同一个配置内必须唯一，便于在历史和界面里区分。
- 规则草稿的试运行在独立线程进行；关闭窗口会请求取消，已开始的那一次
  计算可能在后台再多跑一小段才退出（不阻塞界面、不回填迟到结果）。
- 「保存为长期规则」必须基于一次**当前的**试运行结果；改了任何匹配/目标字段
  （含内部路径方式与取值）都要重新试运行，否则保存会被拒绝。
- 历史导出里旧批次（V1.5 之前）的「规则标识 / 命中依据」为空，属正常。
- 方案只迁移「推荐模式 + 长期修正规则」，不迁移「按类型」「按课程再按类型」
  的独立规则；方案库/导入界面已明确说明。
- 合并冲突不会静默改名、改优先级或猜学期；需要用户逐条选择「采用导入」。
- 目标树与筛选都只影响查看，不会创建目录或改变计划与勾选。
- 方案库默认写入系统用户配置目录；测试可通过环境变量
  `ARCHIVEBOX_SCHEME_DIR` 指向独立临时目录，避免修改真实方案库。
- 重复文件只读核对：本轮不提供删除、合并、自动勾选或释放空间功能；
  内容相同不代表可以直接删除。
- 重复核对范围仅限当前扫描纳入的文件；被保护/排除区域不在范围内。
- 最近空间记录仅为本机使用状态；不进入方案文件、导出包或 Windows 交接包。
- 待整理清单本轮不做跨根目录执行队列；多个空间需分别整理。
- 清单范围扫描复用既有扫描与保护机制，不是独立增量扫描引擎。
