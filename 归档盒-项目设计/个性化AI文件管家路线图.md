# 归档盒个性化 AI 文件管家路线图

归档盒帮助用户理解和整理本地文件。系统从用户选定的目录、文件内容和已有目录结构推断文件归属，必要时针对关键歧义提问，给出可解释的整理建议。课程 MVP 用真实样本证明「理解文件、复用偏好、安全整理」的闭环，长期产品沿用同一套源码，逐步验证日常使用价值。

## 产品边界

1. **实际文件操作须确认。** 模型只提供建议。用户审核最终批次后，程序才校验路径、源文件状态和同名冲突并执行。方案变动后重新确认。
2. **候选偏好须确认后生效。** 一次修正可以只用于本次计划。用户可以查看、修改和停用已确认的偏好。
3. **优先保留原目录结构。** 优先推荐现有合适目录。目录重构独立预览、独立确认。

沿用 Python、PySide6 和 SQLite，复用已有的扫描、规则、预览、安全执行及历史模块。文件分析和模型调用在后台进行。规则整理在关闭联网功能时仍可使用。调用云端模型前说明拟发送的字段或内容，由用户决定授权范围。文件正文按待分析数据处理。模型建议进入预览前由程序校验。

## 阶段 0 · 现有项目审计（当前）

- 固定当前 Git 提交，核对启动入口、依赖、当前源码、交接文档和回归记录。
- 追踪「选择空间 → 扫描 → 分类 → 预览 → 确认 → 执行 → 历史、撤销与恢复」的实际调用。核对 OCR、DeepSeek 补充分类、单文件修正、长期规则与配置持久化的现状。
- 为文件正文与目录上下文分析、AI 结构化建议与提问、偏好确认与复用标出缺口、复用模块、接入位置和最小验证样本。
- **完成条件**　交付《项目现状与增量改造方案》。每项已有能力有源码或实测依据，每项改造有接入点和可复现的验收场景。标明待验证的环境和功能。

## 阶段 1 · 智能整理 MVP

- 选定整理空间后，读取支持的文件内容和目录上下文。先识别主题、课程或项目归属，再结合已有目录与规则生成建议。
- 预览显示源文件、建议去向、依据和影响范围。对会实质改变结果的歧义少量提问，用户跳过时相关文件可以保持原位。
- 将模型返回的文件标识、目标与建议动作转成程序能校验的结构化结果，接入现有计划预览。
- **完成条件**　混合课程资料、项目文档和下载文件可以生成草案。含有相同或模糊文件名的样本能用正文或目录上下文区分。非法目标和未确认草案不会触发文件修改。

## 阶段 2 · 个性化记忆闭环

- 在计划修正时提供「仅改本次」和「保存为长期偏好」。在本地 SQLite 持久化已确认偏好及作用范围，支持查询、修改和停用。
- 下次分析时检索适用偏好。当前明确指令与历史偏好冲突时遵守安全限制和本次指令。同等级的有效偏好冲突时请用户确认。
- **完成条件**　用两轮不同样本验证。例如先确认「开发文档按项目归档」，重启后加入同项目的新文件，建议体现该偏好。单次修正和未确认候选不会影响下一轮。

## 阶段 3 · 稳定交付课程项目

- 将改动集中在核心流程和阻断缺陷。验证批次确认、预览与执行一致、源文件变化、同名保护、取消、中断恢复和撤销。
- 在独立样本或副本中，用路径、数量和内容指纹核对执行和恢复结果。记录实际测试环境、结果、退出码和未测边界。
- 准备可复现的演示、课程报告及真实 TRAE 提示词、修改记录、截图和测试证据。保留可复现的失败、原因及人工介入记录。
- **完成条件**　演示能够从首次分析走到用户确认、第二轮偏好复用和安全撤销。报告中的实现、未达目标和验证结论均有对应证据。

## 阶段 4 · 日常使用版

- 用有备份的资料副本或明确授权的低风险目录试用，根据实际问题改善大目录扫描、增量处理、内容解析、批量预览、检索和错误恢复。
- 记录分类质量、人工修正、耗时和模型成本。完善独立安装、首次启动、升级与旧配置及历史兼容。
- Mac 继续作为主开发环境。涉及文件操作的改动在 Mac 和拯救者的原生 Windows 上用独立样本核对，Windows 补齐长路径、占用、权限、大小写、联接点和桌面交互验证。双端稳定后，按需用 WSL 验证 Linux 核心逻辑，再在 Linux 桌面环境独立验证安装和交互。
- **完成条件**　本人能在常见整理场景中持续使用并完成恢复。目标平台的安装、核心流程和支持范围有各自的验证记录。跨卷和外接盘的断连、恢复及元数据保留需独立验证。

## 阶段 5 · 主动学习与智能管理

- 汇总反复出现的修正、拒绝和撤销，生成可查看依据与作用范围的候选偏好，经用户确认后应用。
- 按需求建立语义索引，识别跨目录的课程、主题、项目及文件版本关联。
- **完成条件**　候选偏好有可追溯的反馈依据。与固定样本基线比较，人工干预减少且分类质量不下降。用户能拒绝候选或停用已保存偏好。

## 阶段 6 · 个人文件管理 Agent

- 支持按自然语言提出多步整理与查找任务。先给出影响范围和可审核的操作方案，再按确认的批次执行。
- 按实际需求评估跨设备管理、NAS、同步和移动端。涉及不同设备和存储的操作分别验证权限、冲突、离线和恢复。
- **完成条件**　文件理解、偏好复用和安全执行已有日常使用证据。Agent 能完成可追踪的多步任务，并在需要变更文件或重构目录时请求对应确认。
