# 阶段三演示步骤

复核时先看提交哈希，再按下面的入口重放。自动化证据在 `课程交付/证据/阶段三回归.log`，第一次预览的真实窗口画面在 `课程交付/证据/截图/01-首次预览.png`。

## 样本入口

在仓库根目录执行：

```bash
python3 课程交付/重置演示样本.py
```

它会补上还没有的演示文件。再次运行时：

- 原路径还在、身份（设备号 + inode）与清单一致：只写回本脚本创建的这份普通文件。
- 原路径已被程序移进 `_已整理`：在整理空间内按清单记录的设备号和 inode 找回，移回原路径，再写回初始内容。不按文件名搜索，也不删除别的文件。同一卷上找不到该 inode 时改为新建，并打印未找到；找到多个同 inode 的文件时不移动。跨卷移动本轮没有环境，未验证。
- 路径上已经存在的用户文件、符号链接，以及链接指向的目录外文件，都不会改写。身份与清单不一致的文件原样保留。

演示开始前已经存在的空间偏好会保留，这个空间后来再确认的偏好也会保留。只有一开始没有偏好的演示目录，才会在下一次重置时拿掉演示过程中新确认的偏好，于是 `开发说明.md` 回到待定且未勾选。范围外对照如果已经是符号链接，包括指向还不存在的文件，脚本不会跟随。操作历史和其他文件保留。

若目录里除 3 份演示文件外还有普通文件，扫描行数会多于 3。`_已整理` 和 `.organizer` 不参与扫描，所以放在 `_已整理/` 里的用户文件不会进预览表。要得到严格的 3 行预览，把目录当专用的空演示目录使用；带用户材料的目录按实际行数核对。

| 相对路径 | 内容 |
|---|---|
| `下载/归档盒/开发说明.md` | 接口说明与排期 |
| `下载/笔记.txt` | 高等数学 极限 导数 |
| `项目/AIGC/项目说明.md` | 项目会议记录 |

空间外对照写在 `课程交付/范围外-不要放进样本.md`。扫描结果里不应出现它。

启动程序使用仓库里的 `归档盒源码`，解释器沿用本机已有虚拟环境。演示前把应用数据指到临时目录，避免写进日常使用的方案和最近空间：

```bash
export ARCHIVEBOX_APP_DIR="$(mktemp -d)"
export ARCHIVEBOX_SCHEME_DIR="$(mktemp -d)"
export ARCHIVEBOX_RECENT_FILE="$(mktemp)"
cd 归档盒源码
../归档盒源码/.venv/bin/python main.py
```

本机复验用的解释器是 `/Users/ypjn/aigc/归档盒源码/.venv/bin/python`。若这台机器没有该路径，使用本仓库 `归档盒源码/.venv`。

窗口抓取（macOS cocoa，不是 offscreen）：

```bash
unset QT_QPA_PLATFORM
/Users/ypjn/aigc/归档盒源码/.venv/bin/python 课程交付/拍摄主窗口.py
```

完整演示过程（第 1 阶段做首次预览与偏好，第 2 阶段重新打开同一目录做第二轮、执行、历史、撤销）：

```bash

/Users/ypjn/aigc/归档盒源码/.venv/bin/python 课程交付/拍摄演示过程.py \

## 手工演示

每一步都从主窗口进入。文件是否被移动，用样本目录里的相对路径核对；内容用 SHA-256 核对；批次用「操作历史」。

1. **选择空间。** 点「选择文件夹」，选 `课程交付/演示样本`。路径栏应显示该目录。此时文件还在原处。
2. **扫描并生成预览。** 点「重新扫描」。状态栏应出现「计划 3 个文件，已选 2」。表格三行：
   - `下载/归档盒/开发说明.md` 不勾选，目标含 `_已整理/待定/`，状态「待定」
   - `下载/笔记.txt` 勾选，依据含「高等数学」，目标含 `_已整理/课程/`
   - `项目/AIGC/项目说明.md` 勾选，依据含顶层目录「项目」
   对应画面：`课程交付/证据/截图/01-首次预览.png`。对应断言：回归日志 S01。范围外文件不在表里。
3. **确认一条空间偏好。** 选中开发说明那一行，点「修改这一行」，再点「保存为长期规则…」。名称填「开发文档按项目归档」，匹配用目录范围，来源目录 `下载/归档盒`，包含子目录，方向「项目」，类别「归档盒」，内部路径清空，范围选当前空间。先点「试运行」，对话框里应能看到匹配条件、适用范围和命中后的目标，再确认保存。取消和直接关闭都不写偏好。关闭窗口。本轮原生运行记录见 `证据/阶段三演示运行-20261116.log`。
4. **第二轮。** 在 `下载/归档盒/` 放一份新的 `接口草稿.md`。重新打开同一空间并扫描。这一行应显示偏好名称「开发文档按项目归档」、依据里的偏好编号，以及目标 `_已整理/项目/归档盒/接口草稿.md`。对应断言：S02。
5. **对照「仅改本次」。** 另放 `下载/临时稿.md`。它不会出现在当前这次预览里，先点「重新扫描」。扫描完成后选中这一行，在修正窗口只点「仅改本次」，不要点「保存为长期规则…」。预览目标可以变，偏好库行数不变。待定行默认不勾选，所以它不会跟着后面的批次移动，除非再勾上。
6. **取消确认。** 取消勾选 `接口草稿.md`，点「开始整理」，在确认框点「取消」。两份对照文件的路径和 SHA-256 都应保持取消前的值。对应断言：S03 的「取消后sha=True」。
7. **确认执行。** 再次点「开始整理」，点「确认开始整理」。只移动当时勾选的行。本轮自动化里实际移动了 3 个：开发说明、笔记、项目说明。接口草稿留在 `下载/归档盒/接口草稿.md`。笔记的目标与预览一致，历史里的 SHA-256 与移动前一致。对应断言：S03。
8. **查看历史。** 点「操作历史」。最新批次状态为已完成，三条动作都是 moved，源路径、目标路径和 SHA-256 与上一步一致。
9. **撤销。** 回到主窗口点「撤销上一次」，并确认。笔记回到 `下载/笔记.txt`，SHA-256 与移动前相同，目标路径不再存在。历史状态变为 undone。对应断言：S04。

安全场景不放进这套小样的手工点击，避免把样本弄乱。它们由同一测试脚本在独立临时目录里复现，见下一节。

S01 到 S04 走真实主窗口。S05 的扫描和预览也走主窗口，随后直接调用执行器，以便在预览之后改文件。S07、S08、S09 是执行器与历史库上的取消、故障注入和恢复，不经过确认框。

S18–S20 用真实 `MainWindow` 完成扫描、偏好确认、执行和撤销，S18、S19 的「再重置」用子进程调用同一个 `重置演示样本.py`。S20 的撤销在重置之后执行：三份演示文件已回到原路径，目标位置不存在，撤销按现有规则逐条报「目标文件已消失」，不删除、不改写文件；批次不会被标成完整成功。

```

退出码 0，且末行是「合计 23 项：通过 23 / 未通过 0」。S12 检查已有文件和指向目录外的符号链接都不被改写。S13 检查空演示目录保存偏好后再次重置，`开发说明.md` 回到待定且未勾选。S14 检查从未做过演示的整理空间，原有偏好不被删除。S16 检查这类空间在重置之后新确认的偏好，再次重置仍保留。S15 检查清单临时文件名上的符号链接。S17 检查范围外对照是悬空符号链接时，不在目录外创建文件。

## 链接边界的实际结果

原始输出在 `课程交付/证据/阶段三补充复验-20261116.log`。这两项只复验，没有把脚本改成跟随链接：

| 场景 | 实际结果 |
|---|---|
| `preferences.db-wal`、`preferences.db-shm` 是指向目录外的符号链接，目录里已有演示清单 | 目录外两个文件字节不变；清单没有「演示前偏好」时，重置删除本空间 `preferences.db`，跳过这两个链接；链接本身仍在 |
| 同上，但目录还没有演示清单（第一次接触） | 脚本打印「偏好库无法安全读取，未改动」，目录外字节不变；直接打开这种库时 SQLite 报 `OperationalError: unable to open database file` |
| `classification_config.json` 本身是指向目录外的符号链接 | 目录外配置字节不变，脚本打印「跳过：分类配置是符号链接，未改偏好」；长期规则继续命中，这种目录不能声称已回到首次预览 |
