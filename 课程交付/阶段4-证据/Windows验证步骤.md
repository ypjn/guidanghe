# 归档盒 V1.7 · Windows 原生验证步骤

本包在 Mac 上交叉组装，尚未在 Windows 原生系统运行。请在拯救者 Y9000P 上按下面步骤验证，并把结果填进 `Windows结果记录模板.md`。不要用真实 NEU 资料的原件，先复制到独立样本目录。

## 0. 校验安装包

1. 把 `归档盒-Windows-免安装.zip` 拷到 Windows。
2. 计算 SHA-256，确认与 `阶段四-安装包校验和.txt` 一致：
   PowerShell：`Get-FileHash .\归档盒-Windows-免安装.zip -Algorithm SHA256`
3. 解压到含中文和空格的路径，例如 `D:\归档盒 测试\`.

## 1. 首次启动与核心流程

1. 双击 `归档盒.exe`，确认窗口标题为 `归档盒 V1.7`。
2. 选择一个独立样本目录（含课程、竞赛、项目、下载文件）。
3. 点「扫描」，观察状态栏是否显示扫描阶段和已发现数量。
4. 生成预览，确认筛选、搜索、勾选和「计划/可见/已勾选」计数一致。
5. 取消确认一次，确认文件没有被移动。
6. 重新确认，只移动勾选项；打开「操作历史」，记录批次号、状态、每项路径和 SHA-256。
7. 撤销该批次，核对文件回到原路径、数量与 SHA-256 一致。
8. 制造一次中断（执行中关闭程序），重开后点「核对恢复」，记录补记/仍未执行项。

## 2. 必测边界

| 场景 | 操作 | 记录 |
|---|---|---|
| 中文与空格路径 | 样本目录用 `D:\归档盒 测试\课程 资料\` | 入口、扫描、执行、撤销是否正常 |
| 长路径 | 构造总长度超过 260 字符的目录/文件名 | 能否扫描、预览、执行、撤销 |
| 文件被占用 | 用 Word/Excel 打开样本文件后执行整理 | 是否明确提示占用，其他文件是否继续 |
| 权限不足 | 对样本文件/目录去掉当前用户读取权限 | 是否给出可理解原因，其他文件是否继续 |
| 大小写冲突 | 同目录放 `Note.txt` 与 `note.txt` | 预览/执行是否分配唯一名、不覆盖 |
| 目录联接 | 用 `mklink /J` 建联接目录 | 是否整体跳过并说明，不跟随到联接目标 |
| 显示缩放 | 分别在 100%、125%、150% 下打开 | 窗口、按钮、表格、确认框是否可用 |

每项记录：实际路径、文件数、SHA-256、历史状态、缩放比例；跳过的项写原因。

## 3. 结果回传

1. 填写 `Windows结果记录模板.md`。
2. 保存「操作历史」导出的 CSV/JSON。
3. 保存失败提示和关键窗口截图。
4. 把结果文件、截图、导出的历史记录放回同一个目录，交给验收。

如果某步无法完成，写「未通过」或「未测」并附现象，不要为了通过而跳过。
