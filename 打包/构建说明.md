# 应用构建与发布验收

当前产品版本见 `归档盒源码/app_metadata.py`（1.8.3）。脚本不写死某台电脑的解释器路径。

## macOS（Apple 芯片 → `.app` + 只读 DMG）

环境：

- macOS 12 或更新版本，Apple 芯片
- Python 3.14，并安装与 `归档盒源码/requirements.txt` 相同的依赖
- PyInstaller 6.22（本机已验证；其他 6.x 需重新做启动验收）
- 系统自带的 `iconutil`、`hdiutil`、`codesign`

```sh
export ARCHIVEBOX_BUILD_PYTHON="/path/to/python"
zsh 打包/build_mac.sh
zsh 打包/accept_mac_app.sh 打包/dist/归档盒-1.8.3-macos-arm64.dmg docs/product-development/evidence/batch07
```

未设置环境变量时，脚本才会使用仓库内的 `归档盒源码/.venv/bin/python`。打包命令是 `python -m PyInstaller`。`archivebox.spec` 已纳入搜索、索引、卷身份与备份模块。

产物：`打包/dist/归档盒.app`、`打包/dist/归档盒-<版本>-macos-arm64.dmg`、`打包/dist/SHA256SUMS.txt`。本地 ad-hoc 签名；Apple 开发者签名和公证还没做。

## 非 Mac 机器上的发布准备

Linux/Windows 云端无法调用 `hdiutil`/`codesign`。可先打源码发布包，再拿到 Mac 生成 DMG：

```sh
bash 打包/make_release_bundle.sh
"$ARCHIVEBOX_BUILD_PYTHON" 打包/verify_release_features.py
```

`verify_release_features.py` 在隔离数据目录核对：搜索三份反例、备份恢复、索引 schema 升级、新模块可导入。

## Windows 免安装包

在 Mac 上交叉组装标准 ZIP（只含 PySide6 6.12.0 与 pypdf 6.4.0，不含 watchdog、pypdfium2、RapidOCR）：

```sh
export ARCHIVEBOX_BUILD_PYTHON="/path/to/python"
zsh 打包/build_windows.sh
```

产物：`打包/dist/归档盒-<版本>-windows-x64.zip`。原生 Windows 仍可用：

```powershell
powershell -ExecutionPolicy Bypass -File 打包/build_windows.ps1 `
  -PythonExe "C:\path\to\python.exe" `
  -GoExe "C:\Program Files\Go\bin\go.exe"
```

依赖入口统一为 `打包/requirements-windows.txt`（含 `pypdf==6.4.0`）。Go 启动器参数透传仍建议在原生 Windows 单独验收；也可用包内 `启动归档盒.bat` / `python app\main.py` 做功能验证。

## 数据位置（升级兼容）

- 方案库、全局偏好、多空间索引：用户应用数据目录
- 启动日志：用户日志目录
- 每个整理空间的历史/偏好/撤销：该空间 `.organizer`

升级不清理旧整理历史；索引 schema 2→3 会迁移并回填卷身份。
