# 归档盒分类手册

> 2026-11-23。这是给程序用的分类记录，不是一篇整理散文。
> 现在只是手册。提示词、`DIRECTIONS`、目录规则都还没改。
> 一个整理空间只用一个包。默认包仍是学习。

一份文件只进一个文件夹。模型以后只填标准名和属性，路径由程序按本手册的模板填，填出来的标准名必须在当前包里。

## 1. 启用顺序

一次只启用一个新包。学习包已经在程序里，不要重写。

1. 学习。继续用 `general_catalog.py`、`contest_catalog.py`、`professional_catalog.py`。
2. 财务。第一份要新写进规则的包。方向里还没有「财务」，启用前要先让程序接受这个方向。
3. 证件、健康、住家、车辆。都是办事时会找的原件，互不替代。
4. 合同、工作、购物、出行。文件更少，等财务包用真实文件名对过再开。
5. 照片。要等程序能读拍摄日期。读不到时，只认文件名里已经写明的日期。

整本手册不要放进同一次提示。当前补充分类最多带 80 对「方向 + 类别」，单次最多 40 个文件，正文最多 1200 字。一个包控制在 40 个标准名以内。

## 3. 一条记录长什么样

每条记录固定这几项。说法长的在前，短的在后，避免「发票」抢走「电子发票」。

- 标准名：文件夹名，也是模型允许返回的类别。
- 说法：文件名或正文里会出现的词。
- 属性：程序能读到、并且路径用得上的字段。读不到就留空。
- 路径：程序填写的模板。`{年}` 来自文件名或正文里的日期，四位年份。
- 跳过：什么情况下不要归入这一条。
- 两例：一个顺利，一个容易归错。

## 4. 先看文件是哪种，再选包

财务优先。文件名或正文能读出发票、收据、工资、报销、纳税时，归财务，哪怕对方是医院、航空公司或供电局。

归不进财务时，按你会先去哪个抽屉找：

| 你要找的 | 包 |
| --- | --- |
| 这门课、这场竞赛、这份校园材料 | 学习 |
| 这张票、这笔钱、这一年的税 | 财务 |
| 办事要出示的证 | 证件 |
| 体检、病历、化验、疫苗、医保 | 健康 |
| 这套房的权属、租约、保险、水电、维修 | 住家 |
| 这辆车的证件、保险、维修 | 车辆 |
| 和谁签的约，又不属于上面某套房、某辆车 | 合同 |
| 入职、离职、在职证明 | 工作 |
| 保修卡、说明书 | 购物 |
| 什么时候拍的 | 照片 |
| 哪一次出行的预订确认 | 出行 |

学习空间里见到发票、护照、体检：保持待定，不要塞进课程或校园事务。生活空间里见到作业和竞赛：保持待定，不要塞进财务。

## 5. 学习包

这个包就是现有目录，本手册不另抄一份关键词。

- 课程：`GENERAL_COURSE_RULES`、`PROFESSIONAL_COURSE_RULES`，以及学期目录映射。路径维持 `_已整理/课程/{学期}/{课程}/文档`。
- 竞赛：`CONTEST_CATALOG`。长名称优先。
- 校园事务：`GENERAL_CAMPUS_RULES`。奖学金、综测、请假、成绩单、证明、实习、周报、通知留在这里。
- 项目：现有顶层目录映射（代码、项目、大创）。PARA 的「项目」不新增类别。

已经按课程目录认走的文件，不要改判成生活包。按类型整理时仍然只看扩展名，本手册不参与。

## 6. 财务包

路径都在 `_已整理/财务/` 下。`{年}` 用开票日、入账日或所属纳税年度，不用文件修改时间。对方读不到就省略，路径里不单开「未知对方」。

### 发票

- 说法：增值税电子普通发票、增值税专用发票、电子发票、购物发票、发票
- 属性：年、对方
- 路径：`_已整理/财务/发票/{年}/`
- 跳过：文件里没有发票字样，也没有价税合计或发票代码。保修卡、说明书、保单不是发票。
- 例：`2026-03-14 京东 发票.pdf` → `_已整理/财务/发票/2026/`
- 例：`滴滴出行电子发票.pdf` → 财务/发票，不进出行。年从正文取，取不到就停在 `_已整理/财务/发票/`。

### 收据

- 说法：收款收据、缴费收据、收据、小票
- 属性：年、对方
- 路径：`_已整理/财务/收据/{年}/`
- 跳过：已经能确定是发票的，归发票。银行回单归银行账户。
- 例：`2026-11-02 换机油 收据.jpg` → `_已整理/财务/收据/2026/`
- 例：`超市小票.jpg` 且读不出日期和店名 → 跳过。

### 工资单

- 说法：工资发放明细、薪资单、工资条、工资单
- 属性：年、所属月
- 路径：`_已整理/财务/工资单/{年}/`
- 跳过：劳动合同、录用通知。
- 例：`2026-01 工资单.pdf` → `_已整理/财务/工资单/2026/`
- 例：`银行代发工资回单.pdf` → 银行账户，不进工资单。

### 报销

- 说法：费用报销单、报销审批、报销单、差旅报销
- 属性：年
- 路径：`_已整理/财务/报销/{年}/`
- 跳过：作为附件的单张发票仍归发票。报销单本身归这里。
- 例：`2026-04 差旅报销单.pdf` → `_已整理/财务/报销/2026/`
- 例：`报销用 滴滴发票.pdf` → 发票。

### 银行账户

- 说法：银行对账单、账户交易明细、银行流水、存款证明
- 属性：年、机构
- 路径：`_已整理/财务/银行账户/{年}/`
- 跳过：银行卡照片若只是卡面、没有流水，归证件里的身份材料也不合适，跳过。不要把卡号写进路径。
- 例：`2026 招商银行 流水.pdf` → `_已整理/财务/银行账户/2026/`
- 例：`工资卡照片.jpg` → 跳过。

### 信用卡

- 说法：信用卡账单、信用卡还款
- 属性：年、机构
- 路径：`_已整理/财务/信用卡/{年}/`
- 跳过：借记卡流水归银行账户。
- 例：`2026-08 信用卡账单.pdf` → `_已整理/财务/信用卡/2026/`
- 例：`信用卡 电子发票.pdf` → 发票。

### 纳税

- 说法：个人所得税纳税记录、年度汇算、完税证明、纳税证明
- 属性：年
- 路径：`_已整理/财务/纳税/{年}/`
- 跳过：单张购物发票留在发票。只有汇算、完税、纳税记录进这里。
- 例：`2025 年度汇算.pdf` → `_已整理/财务/纳税/2025/`
- 例：`发票.pdf` → 发票，即使是为了报税下载的。

### 投资

- 说法：基金对账单、证券对账单、投资收益
- 属性：年、机构
- 路径：`_已整理/财务/投资/{年}/`
- 跳过：只写「股票」两个字、没有机构或年份的笔记、截图说明。
- 例：`2026 天天基金 对账单.pdf` → `_已整理/财务/投资/2026/`
- 例：`理财心得.txt` → 跳过。

### 贷款

- 说法：房贷还款计划、贷款合同还款、贷款还款明细、还款计划
- 属性：年、机构
- 路径：`_已整理/财务/贷款/{年}/`
- 跳过：房屋买卖合同、抵押合同归合同或住家，不进还款明细。
- 例：`2026 公积金贷款 还款明细.pdf` → `_已整理/财务/贷款/2026/`
- 例：`房屋买卖合同.pdf` → 住家/房屋权属。

## 7. 证件包

原件和扫描件同一标准名。每人一个子文件夹只在文件名或正文能读出姓名时使用，读不出就不要建「未知」。

### 身份证件

- 说法：居民身份证、身份证
- 属性：人
- 路径：`_已整理/证件/身份证件/{人}/`
- 跳过：身份证号不进路径。学生证、工作证不进这一条。
- 例：`张三 身份证 正面.jpg` → `_已整理/证件/身份证件/张三/`
- 例：`身份证号登记表.xlsx` 若是班级表格 → 学习包的校园事务；生活空间里无法判断属于谁 → 跳过。

### 户口

- 说法：居民户口簿、户口本、户籍证明
- 属性：无额外分层
- 路径：`_已整理/证件/户口/`
- 跳过：不要按每一页家庭成员再拆文件夹。
- 例：`户口本.pdf` → `_已整理/证件/户口/`
- 例：`集体户口首页.jpg` → 同一路径。

### 护照与通行证

- 说法：往来港澳通行证、护照、通行证
- 属性：人
- 路径：`_已整理/证件/护照与通行证/{人}/`
- 跳过：签证页和机票预订单不是证件。预订单归出行。
- 例：`李四 护照.pdf` → `_已整理/证件/护照与通行证/李四/`
- 例：`2026-05-01 上海 机票行程单.pdf` 且含发票或行程单 → 财务/发票。

### 学历证书

- 说法：学位证书、毕业证书、学历证书、成绩单
- 属性：人
- 路径：`_已整理/证件/学历证书/{人}/`
- 跳过：在学习包里，成绩单已经归校园事务，作业和论文归课程。只有离开学校空间、当作证件保存的扫描件进这里。
- 例：`张三 毕业证书.pdf` → `_已整理/证件/学历证书/张三/`
- 例：`高等数学 期末试卷.pdf` → 学习包，不进学历证书。

### 资格证书

- 说法：职业资格证书、职称证书、资格证书、证书
- 属性：人
- 路径：`_已整理/证件/资格证书/{人}/`
- 跳过：单独一个「证书」太宽。旁边没有职业、职称、资格、英语等级这类词时跳过。奖状归荣誉证书。
- 例：`张三 教师资格证.pdf` → `_已整理/证件/资格证书/张三/`
- 例：`证书.pdf` → 跳过。

### 婚姻证件

- 说法：结婚证、离婚证
- 属性：无额外分层
- 路径：`_已整理/证件/婚姻证件/`
- 跳过：婚礼照片归照片。婚宴发票归财务。
- 例：`结婚证.pdf` → `_已整理/证件/婚姻证件/`
- 例：`婚礼 全家福.jpg` → 照片。

### 荣誉证书

- 说法：荣誉证书、奖状、获奖证书
- 属性：人、年
- 路径：`_已整理/证件/荣誉证书/{年}/`
- 跳过：学习包里的奖学金、竞赛获奖走校园事务和竞赛，不进这里。
- 例：`2024 三好学生 奖状.jpg` → `_已整理/证件/荣誉证书/2024/`
- 例：`数学建模竞赛 获奖证书.pdf` 且当前包是学习 → 竞赛，不进荣誉证书。

## 8. 健康包

医院开的发票、收据仍归财务。这里只留看病和体检记录。

### 体检

- 说法：健康体检报告、体检报告、体检
- 属性：人、年
- 路径：`_已整理/健康/体检/{人}/{年}/`
- 跳过：读不出是谁的体检，就不要猜姓名。年份也读不到则跳过。
- 例：`2026 张三 体检报告.pdf` → `_已整理/健康/体检/张三/2026/`
- 例：`体检中心发票.pdf` → 财务/发票。

### 病历

- 说法：门诊病历、出院记录、病历
- 属性：人、年
- 路径：`_已整理/健康/病历/{人}/{年}/`
- 跳过：只有「医院」两个字的照片、导航截图。
- 例：`2025 张三 门诊病历.pdf` → `_已整理/健康/病历/张三/2025/`
- 例：`协和医院.jpg` → 跳过。

### 检验单

- 说法：检验报告、化验单、检查报告
- 属性：人、年
- 路径：`_已整理/健康/检验单/{人}/{年}/`
- 跳过：体检报告整本归体检，不要把其中一页改判成检验单。
- 例：`2026-02 血常规.pdf` → 年能读到就 `_已整理/健康/检验单/2026/`；人读不到就省略人这一层。
- 例：`年度体检报告.pdf` → 体检。

### 疫苗

- 说法：预防接种证、疫苗接种记录、接种记录
- 属性：人
- 路径：`_已整理/健康/疫苗/{人}/`
- 跳过：接种预约短信、医院发票。
- 例：`张三 预防接种证.pdf` → `_已整理/健康/疫苗/张三/`
- 例：`疫苗接种 缴费发票.pdf` → 财务/发票。

### 医保

- 说法：医保结算单、费用结算单、医保
- 属性：人、年
- 路径：`_已整理/健康/医保/{年}/`
- 跳过：标题是发票的医疗收费归财务。商业医疗保险合同归车辆或住家或合同，不进医保。
- 例：`2026 医保结算单.pdf` → `_已整理/健康/医保/2026/`
- 例：`医疗收费电子发票.pdf` → 财务/发票。

## 9. 住家包

一套房一个主题。保险、租约跟这套房走，不另做一套「所有合同」文件夹。

### 房屋权属

- 说法：不动产权证书、房屋所有权证、房产证、房屋买卖合同
- 属性：无额外分层
- 路径：`_已整理/住家/房屋权属/`
- 跳过：中介带看记录、房价截图。
- 例：`不动产权证书.pdf` → `_已整理/住家/房屋权属/`
- 例：`买房发票.pdf` → 财务/发票。

### 租赁合同

- 说法：房屋租赁合同、租房合同、租约
- 属性：年
- 路径：`_已整理/住家/租赁合同/{年}/`
- 跳过：租房押金收据归财务/收据。已经退租、只是留档的，仍用同一标准名，不要建「过期」文件夹。
- 例：`2025 房屋租赁合同.pdf` → `_已整理/住家/租赁合同/2025/`
- 例：`押金收据.pdf` → 财务/收据。

### 房屋保险

- 说法：家财险保单、房屋保险、租客保险
- 属性：年
- 路径：`_已整理/住家/房屋保险/{年}/`
- 跳过：车险、说不清保的是什么的保单。保费发票归财务。
- 例：`2026 家财险保单.pdf` → `_已整理/住家/房屋保险/2026/`
- 例：`保险费发票.pdf` → 财务/发票。

### 水电燃

- 说法：电费账单、水费账单、燃气账单、水电费
- 属性：年
- 路径：`_已整理/住家/水电燃/{年}/`
- 跳过：标题含发票的，归财务/发票。
- 例：`2026-07 电费账单.pdf` → `_已整理/住家/水电燃/2026/`
- 例：`供电 电子发票.pdf` → 财务/发票。

### 房屋维修

- 属性：年

## 14. 照片包

照片不按「旅游」「家人」「生活」分类。同一张照片往往每条都能贴上，分开就会有两个家。

### 照片

- 说法：照片、IMG_、DSC、截图以外的图像。截图不进这一条。
- 属性：拍摄年、拍摄月。来源是文件名里的日期，或以后读到的拍摄日期。

- 跳过：证件扫描件、发票照片、病历照片，分别归证件、财务、健康。没有拍摄日期就跳过，不要用文件修改时间。
- 例：`2026-05-01 全家福.jpg` → `_已整理/照片/2026/2026-05/`
- 例：`身份证 正面.jpg` → 证件/身份证件。

## 16. 不收的类

这些在来源里出现过，归档盒不用它们当标准名：

- 综合、其他、视家庭情况、家庭历史、藏品、图书剪报、书信日记、族谱家训。
- 已付款、未付款、最终版、新建文件夹。状态会变，不进路径。
- 按家庭成员当第一层、里面再套婴幼、学生、工作。学习包已经按课程和学期分，两套叠在一起会对不上。
- 相机型号、拍摄地点、人物脸。照片只留拍摄年月。
- Johnny.Decimal 编号、ScannerOne 的 00–99 前缀、档案盒的件号盒号。

## 18. 写进提示词时要守的限制

还没做。做的时候按这个边界，不要把本文件整篇贴进去。

- 一次只带当前空间选定的那一个包。
- 提示里每条只留标准名、说法、跳过。属性和路径留在程序里。
- 模型返回的类别必须等于某个标准名，否则整条作废，文件保持待定。
- 模型可以返回它读到的年、月、日、人、对方。没读到的字段留空。
- 程序拒绝路径里出现 `..`、绝对路径，以及「已付」「未付」「最终版」。
- 学习包的方向仍然只许是：课程、竞赛、项目、校园事务、待定。
- 按类型整理不调用这本手册。
