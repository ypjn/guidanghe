# 归档盒产品方向备忘（2026-11-22）

## 已定策略

- **不做本地大模型**：能力与性价比不足；AI 仅自备 API。
- **OCR 选装**：不进标准 Windows ZIP；官网提供下载渠道。
- **监视文件夹**：默认关闭。若做，必须是显式开关，避免「常驻监视」观感。
- **语义检索**：后期待办，不挡当前交付。

## 场景扩展（当前 → 全领域）

当前主场景仍是课程/学习资料。落地全领域时按优先级引入：

1. **规则链式自动整理**（先匹配先生效 → 只生成预览方案）
2. **照片按 EXIF 建树**（日期/设备；预览确认后才移动）
3. **重复核对加深** + **有证据的关联/邻域**（对照 OmniSorSe：DocumentSet 与语义分开展示；我们只做 deterministic）
