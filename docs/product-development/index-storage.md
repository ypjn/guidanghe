# 本地文件空间索引

索引数据库在用户数据目录的 `index/index.db`，可以用 `ARCHIVEBOX_INDEX_DB` 指到测试库。它和每个整理空间里的 `.organizer` 历史、偏好、撤销记录分开。索引可以整库重建；重建写到旁边的新文件，替换成功前原来的库仍可查询。打不开的库会改名保留，不直接删掉。

一条文件记录用空间 ID 加规范化相对路径标识。路径改名会留下旧记录并新增新记录，不用裸 inode 当作跨设备身份。macOS 上大小、mtime 和 ctime 都没变时才复用已保存的内容校验；Windows 的 ctime 是创建时间，不能据此跳过重读。

排除目录、受保护项目和明确禁止读取的路径默认不进索引。用户可以把受保护项目标成只读纳入，这不会改变整理时的移动保护。`_已整理` 可以索引。符号链接默认不跟随。扫描没完成的目录里，旧文件不会被判成已删除。

正文放在同一库的 `chunks` 表，并用 FTS5 trigram 索引。三个及以上字符按连续片段查找，因此中文词、英文和版本号都能对上。一到两个字符（例如「图」「实验」）trigram 对不上，改用转义后的连续匹配，并且受分页上限约束。查询只作为参数传入。分类仍使用原来最多 4KB 的短摘录，不拿那段摘录当全文。

PDF 使用 pypdf 6.4.0（BSD-3-Clause，纯 Python）。能复制出文字的页面会留下页码；扫描件、加密、损坏和空白文件记下状态，不渲染、不识别。超时按页或按段落检查。单个页面若在解析函数内部卡住，这一页本身等不到超时，后续文件仍会继续。Office 文档留下段落、幻灯片或工作表编号，不编造页码。超过大小、页数、字符或解压上限的文件标成部分索引，并写明未覆盖的范围。读取前后身份不一致，或目标变成空间外的链接时，这次正文丢弃。暂停正文读取、删除某空间正文、重建正文，都不删除来源文件和整理历史。
